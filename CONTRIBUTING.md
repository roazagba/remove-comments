# Contributing to the Project

Thank you for considering contributing to our project! Here are the steps to get started:

## Fork the Repository
1. Click on the **Fork** button at the top right corner of the repository page.
2. This will create a copy of the repository under your GitHub account.

## Clone the Repository
1. Open your terminal.
2. Run the following command to clone the repository:
   ```
   git clone https://github.com/your-username/remove-comments.git
   ```
   Replace `your-username` with your GitHub username.

## Setup the Project
1. Navigate into the project directory:
   ```
   cd remove-comments
   ```
2. Install the required dependencies. (Instructions may vary depending on the project.)
   ```
   npm install
   ```

## Testing the Project
1. Run the tests to ensure everything is set up correctly:
   ```
   npm test
   ```

## Submit a Pull Request (PR)
1. Create a new branch for your feature or bug fix:
   ```
   git checkout -b feature-name
   ```
2. Make your changes and commit them:
   ```
   git commit -m 'Descriptive commit message'
   ```
3. Push your changes back to your forked repository:
   ```
   git push origin feature-name
   ```
4. Go to the original repository and click on **Pull Requests**.
5. Click **New Pull Request** and select your branch.
6. Submit the PR and wait for feedback!

Thank you for your contributions!
